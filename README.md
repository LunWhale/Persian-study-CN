# 波斯语开口学 · Fārsi for Chinese Beginners

零基础中文用户自学波斯语的**单文件网页应用**（双击即可用，全离线）。

## 🌐 在线地址

GitHub Pages 部署后访问：`https://lunwhale.github.io/Persian-study-CN/`

## ✨ 特性

- 🎧 **1355 个词条卡片**，每词内嵌真人级波斯语神经网络语音（微软 edge-tts），**离线可播**
- 🔤 **发音学院**：6 元音（长短分明）+ 32 字母表（每个字母有名称音与示范词）+ 12 个难音诊所
- 📚 **19 大分类词库**（问候 / 饮食 / 旅行 / 宗教 / 文化…），手风琴折叠分块，支持中文/谐音/转写/波斯语搜索
- 📖 **语法学院**：零基础超详细语法，每个波斯语词都可点读（含复数后缀 -hā、伊扎菲等）
- ✍️ 每条卡片含：原文 + 规范转写(ā/ī/ū/ḵ/ḡ/š/ž/č) + **逐音节切分** + **重音标记** + 汉语谐音 + 发音/连读讲解

## 📁 结构

```
波斯语入门学习.html   ← 成品（单文件，20MB，直接用浏览器打开）
content/            ← 19 个分类词库源数据（JSONL，可编辑）
audio/fa/           ← 词条音频池（sha1(fa).mp3）
build/              ← 生成脚本（validate 校验 / build_html 构建 / 发音与语法源文件）
```

## 🔧 本地重新生成

```bash
# 改完 content/*.jsonl 后重新构建（自动补缺失音频）
python3 build/build_html.py
```

## 🎤 语音

由微软波斯语神经网络声优 fa-IR-DilaraNeural / fa-IR-FaridNeural 合成，base64 内嵌于 HTML。
